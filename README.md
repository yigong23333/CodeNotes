# 读源码笔记

> 用途：读 GitHub 开源项目的学习笔记。每读一个项目写一篇，写成能给别人看懂的形式。
> 建立：2026-10-30　作者：yigong

## 目录说明

| 目录/文件 | 放什么 |
|---|---|
| `00-阅读方法.md` | 读源码的固定套路 + Git 命令速查 + 国内加速办法 |
| `01-项目清单/` | 按方向整理的值得读的项目（带链接和一句话说明） |
| `notes/` | 每个项目一篇阅读笔记 |
| `99-模板/项目笔记模板.md` | 新建笔记时复制这个 |

## 规矩

- 一个项目一篇，文件名 = 项目名，例如 `notes/obsidian-git.md`。
- 笔记只写**自己消化过的东西**，不抄 README。写不出"我学到了什么"就说明还没读懂。
- 源码克隆到 `D:\Repos\`，**不进这个仓库**（体积大、且是别人的代码）。
- 本仓库可公开；涉及个人隐私的内容一律不往这里放。
